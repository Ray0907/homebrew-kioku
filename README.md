# homebrew-kioku

Homebrew tap for [kioku](https://github.com/Ray0907/kioku).

```sh
brew install Ray0907/kioku/kioku
brew upgrade kioku
```

Prebuilt binaries for macOS and Linux (arm64, amd64), taken from the kioku GitHub releases and checked against their SHA-256.

Maintainers: after a kioku release, run `./bump.sh vX.Y.Z`, review the diff, commit and push.
